Abstract

Active learning is a machine learning approach in which a model selects the data from which it would benefit most by learning. Instead of labelling an entire dataset, the model requests labels for selected examples from an oracle, such as a human expert. This approach can reduce the amount of labelled training data required. This paper introduces the main principles of active learning, discusses querying strategies and considers how iterative selection can improve the efficiency of model training. The effectiveness of active learning depends on the quality of the selected samples, the reliability of the labels and the stopping criteria used during training.

Introduction

Active Learning (Angluin, 1988; Cohn et al., 1994) is a paradigm where a concept is learnt by an intelligent machine through interaction between an oracle and the machine system over a sequence of learning epochs. A distinctive component of an active learning system is the querying strategy, which selects candidate training instances from a pool and evaluates their informativeness, meaning their potential to improve the classification model.

Various strategies have been proposed, including Query by Committee (Seung et al., 1992), Monte Carlo estimation (Roy and McCallum, 2001), uncertainty sampling (Lewis and Gale, 1994) and version space reduction (Tong and Koller, 2001).

At each epoch, the selected instances are presented to a machine or human oracle that knows the class labels. After the newly labelled instances are added to the current training set, a revised model is trained. The process continues until a stopping criterion is reached. The aim is to improve learning efficiently while reducing the need for large labelled datasets.

Analysis and discussion

Active learning aims to improve the efficiency of machine learning by selecting the most informative examples for labelling. Rather than labelling every available example, the system focuses on data that may provide the greatest improvement to the model.

Uncertainty sampling selects examples for which the model is least confident about its predictions. Query by Committee uses disagreement between multiple models to identify potentially informative examples. These methods can reduce labelling effort, although their performance depends on the dataset and the reliability of the selected labels.

An important consideration is the stopping criterion. If the process continues after useful information has been exhausted, additional labelling may provide little benefit. The quality of the oracle and the selection strategy must therefore be considered when evaluating active learning.
